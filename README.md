# 🐱 Kitty Beach

A fun, fast-paced beach delivery game made for the **Gamedev.js Jam 2026** (Theme: Machines).

### How to Play
- **Drag** Zoey’s claw with your mouse  
- OR use **Left / Right arrows** + **Space** to drop coconuts  
- Click food icons to send **Rusty** on deliveries  
- Protect the kitties from robot cats  
- Defeat the mighty **Arch Cat** boss!

### Features
- Smooth mouse + keyboard controls
- Cute characters and animations
- Robot invasion after 3 deliveries
- Arch Cat boss battle
- Sound toggle + Fullscreen support
- Mobile friendly (landscape mode)

### Tech
- Built with **Phaser 3**
- Music: "Traditions" by [FiftySounds](https://www.fiftysounds.com)
